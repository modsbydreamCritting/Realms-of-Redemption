# Realms of Redemption
Repository for the Realms of Redemption Minecraft mod

(Or maybe I'm wrong maybe I can, I'm no lawyer, but I'd prefer to respect the asset creator's wishes and this seems the best way to go about it)

Any contributions to this code which are accepted will be credited in the mod description (please let me know if I forget to add credit)
